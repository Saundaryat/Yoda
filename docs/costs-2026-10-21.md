# Usage and cost disclosure

Measured October 21, 2026, for the [final comparison](final-experiment.md). Actual Copilot billing/subscription allocation is **unknown**, not $0. Requested model is `gpt-4.1`; served model/provider metadata is blank. No invoice or verified rate card was available. There are no LLM-judge calls.

The export records 67 Hermes turns with raw usage objects. The API leaves `estimatedCostUsd: null` and `costStatus: unknown`. Failed/retried provider requests may not be fully represented in those counters.

| Accounting interpretation | Input tokens | Output tokens |
| --- | --- | --- |
| Maximum reported counter per scenario, summed | 626,775 | 10,341 |
| All reported turn counters summed | 1,029,766 | 16,459 |

These are two interpretations of the available counters, not verified lower/upper billing bounds. The pinned runtime exposes session counters; accumulation/reset/cache/retry semantics have not been independently established. Blindly summing counters could double count; treating them as zero would hide expense.

For a transparent illustrative budget only, assume **$1 per million input tokens and $4 per million output tokens**. These are invented planning assumptions, not current provider prices. Arithmetic yields approximately **$0.67** under the max-counter interpretation or **$1.10** under the summed-counter interpretation for the captured usage. Neither number is a Copilot bill or a validated token-billing estimate. Scaling this hypothetical workload to three repetitions would be roughly $2.00–$3.29 under the same assumptions, before missing usage, retries, or subscription effects.

PostgreSQL, NestJS, Vue, MCP, and Hermes run on the existing local computer; no separate hosting/cloud database was purchased. Hardware, electricity, installed subscription, and engineering time are excluded—not claimed free. Historical development runs, cancellation probes, and failed provider attempts are outside the final-comparison arithmetic and may have incurred additional usage.
